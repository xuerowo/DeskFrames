# DeskFrames 桌面分區框線

在 Windows 桌面上畫出分類框線，把同類檔案圈在一起，並附上不會被圖示擋住的標題；另附一個放在桌面上的待辦清單。

- **只做視覺標示**：框線完全「點穿」，點選、拖曳、雙擊後方的桌面圖示都和平常一樣。
- **永遠在最底層**：框線位於桌面圖示之上、所有視窗之下，不會蓋住任何程式；按 Win+D 顯示桌面時依然可見。
- **任意直角形狀**：長方形、L 形、凸字形、T 形、凹字形……都能做出來。
- **開機自動出現**：位置、形狀、樣式都會保留。
- **極低占用**：閒置時約 11 MB 記憶體、0% CPU（沒有任何計時器在跑，畫面只在變更時重繪）。

## 安裝與執行

1. 需要 [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0)（若用 `build.ps1 -SelfContained` 建置則不需要）。
2. 執行 `dist\DeskFrames.exe`。可以先把它放到固定位置（例如 `%LOCALAPPDATA%\DeskFrames\`）再執行，開機啟動會記錄目前的位置。
   （倉庫只包含原始碼，`dist\` 需自行建置產生。）
3. 第一次啟動會自動進入編輯模式，並預設開啟「開機時自動啟動」（可在設定中關閉）。

自行建置：`powershell -ExecutionPolicy Bypass -File build.ps1`

## 使用方式

| 動作 | 方法 |
|---|---|
| 進入／離開編輯模式 | `Ctrl + Alt + F`，或雙擊系統匣圖示 |
| 顯示／隱藏待辦清單 | `Ctrl + Alt + D` |
| 設定 | 系統匣圖示按右鍵 →「設定…」 |

兩個快捷鍵可在 `config.json` 的 `hotkeyEdit`／`hotkeyTodo` 修改（例如 `"ctrl+alt+d"`、`"win+shift+f2"`），改完重新啟動即可；若被其他程式占用，啟動時會跳出提示。預設已避開 OverlayTranslator 的 `Ctrl+Alt+T`。

### 編輯框線（編輯模式中）

| 想做的事 | 操作 |
|---|---|
| 畫新框線 | 工具列「繪製框線」→ 在桌面上拖曳（`Ctrl+N`） |
| 移動框線 | 拖曳框線內部或標題 |
| 調整大小 | 拖曳任一條邊或角落 |
| 做出凸字形 | **Shift + 拖曳邊線**：從按下的位置拉出一段凸角（往內拖則是凹口） |
| 做出 L 形 | **Shift + 拖曳角落**：把角落切成缺角 |
| 擴大／縮小範圍 | 工具列「加入區塊」／「挖除區塊」，再拖曳出要加入或挖掉的矩形 |
| 快速套用形狀 | 在框線上按右鍵 →「套用形狀」（長方形、L、反 L、凸、T、凹） |
| 改名 | 雙擊標題，或 `F2` |
| 樣式 | 工具列「樣式」：顏色、粗細、圓角、實線／虛線／點線、底色濃度、柔光、標題樣式與位置 |
| 微調位置 | 方向鍵（一次一格），`Ctrl + 方向鍵`（一次 1 像素） |
| 複製／刪除 | `Ctrl + D`／`Del` |
| 復原／重做 | `Ctrl + Z`／`Ctrl + Y` |
| 暫停吸附 | 拖曳時按住 `Alt` |
| 結束編輯 | `Esc` 或「完成」 |

拖曳時會自動吸附到格線、其他框線的邊緣與螢幕邊緣，排版自然整齊。框線畫好後，把桌面圖示拖進框內即可。

### 待辦清單

- 按右上角「＋」（或 `Ctrl + Alt + D`）叫出輸入框，輸入後按 `Enter` 新增，可連續新增；點到別處或按 `Esc` 輸入框就會收起（選單可改為「常駐顯示輸入框」）。
- 點圓圈標記完成；雙擊文字編輯；拖曳可排序。
- **設定時間**：在事項上按右鍵 →「設定時間」（今天 18:00、明天 09:00、下週一 09:00 或自訂日期時間）。時間顯示在事項下方，逾期為紅色、今天到期為藍色；點時間可修改。時間到會跳出 Windows 通知提醒（點通知可開啟清單）。
- 右上「⋯」選單：隱藏已完成、清除已完成、清單樣式、鎖定位置與大小、常駐顯示輸入框、重新命名、隱藏清單。
- **清單樣式**（「⋯」→「清單樣式…」或設定視窗）：主題（跟隨介面／深色／淺色）、自訂背景色與強調色（可輸入色號）、不透明度、文字大小、行距、圓角，即時預覽，可一鍵恢復預設。
- 拖曳標題列移動，拖曳邊緣調整大小。

## 資料位置

設定與框線存放於 `%APPDATA%\DeskFrames\config.json`（設定視窗有「開啟資料夾」按鈕）。
若要移除：在系統匣結束程式、關閉「開機時自動啟動」，再刪除上述資料夾即可。

## 技術說明

- C# / .NET 10 WinForms，全部介面自繪（深色／淺色主題，跟隨系統）。
- 每個框線是一個獨立的逐像素透明分層視窗（`UpdateLayeredWindow` + `WS_EX_TRANSPARENT`），大小只涵蓋框線本身；靜態顯示時會釋放繪圖緩衝，由系統保留畫面。
- 視窗的擁有者設為 Explorer 的桌面視窗，並插入在桌面視窗的正上方，因此在所有視窗之下、Win+D 後仍可見；Explorer 重新啟動後會自動重新附著。
- 框線以「直角多邊形」儲存（`src/Core/RectiPoly.cs`），支援正規化、合法性檢查（不自我相交）、與矩形的聯集／差集、圓角外框路徑。
- 開發用：`DeskFrames.exe --render-preview <資料夾>` 可離屏輸出框線與視窗的預覽圖；`DeskFrames.exe --edit` 切換執行中程式的編輯模式；環境變數 `DESKFRAMES_DATA` 可指定另一個資料夾（並停用登錄檔寫入）以便測試。

```
src/
  Program.cs              進入點、單一執行個體
  Models.cs               設定資料模型與 JSON 儲存
  Native.cs               Win32 互通
  App/AppController*.cs   系統匣、快捷鍵、編輯邏輯、復原/重做、吸附
  Core/RectiPoly.cs       直角多邊形幾何
  Core/DesktopHost.cs     釘選到桌面層
  Frames/                 框線視窗、繪製、工具列、繪製遮罩、改名輸入框
  Todo/                   桌面待辦清單
  UI/                     主題、自繪控制項、設定與樣式視窗
```
